# Change Requests

## Purpose
To log every request that falls outside the agreed `PROJECT_SCOPE.md`, so scope changes are visible, approved deliberately, and never silently absorbed into the fixed-fee engagement.

## Overview
Any request touching a "Not Included" item in `PROJECT_SCOPE.md`, or any change materially larger than the three included revision rounds, should be logged here before work begins on it.

## Current Status
No change requests logged yet — project is in its initial agreed-scope build phase.

## Responsibilities
Each entry should capture: what was requested, why, its impact (time/cost), and its approval status.

## Implementation Notes
**Template for new entries:**

### CR-001 — [Short Title]
- **Requested by:** [Client / Developer]
- **Date:** [YYYY-MM-DD]
- **Description:** [What is being requested]
- **Scope Impact:** [Which excluded item(s) this touches, per `PROJECT_SCOPE.md`]
- **Estimated Impact:** [Time / cost estimate]
- **Approval Status:** Pending / Approved / Declined
- **Notes:** [Any relevant context or client discussion]
